# FE June 2026 Study Plan

to one or two small book sections, usually about 4-8 pages, so it can realistically
fit into the 20-minute reading slot.

The main focus is 科目A. 科目B is only short maintenance.

## Rules for Daily Generation

- Use the day's `20-Minute Reading Assignment`, not the broad chapter range.
- Generate 10 科目A questions.
- At least 2 questions should be from 情報セキュリティ unless it is a pure weekly calculation review.
- At least 2 questions should be from ネットワーク or データベース.
- At least 2 questions should be from マネジメント系 / ストラテジ系 / 法務.
- At least 1 question should be a calculation problem.
- If a question is selected from `data/fe_siken_questions.sqlite`, use the real
  `question_details` content and include `来源URL`.
- If the question has images, use the cached `/assets/fe-siken/...` path.

## Review Priorities

1. 情報セキュリティ: attack names, authentication, MAC/signature/encryption, WAF/IDS/DMZ.
2. ネットワーク: DNS/DHCP/SNMP, IP/subnet, transmission time, protocol purpose.
3. データベース: SQL, normalization, transaction, lock, recovery, constraints.
4. 法務: 個人情報保護法, 著作権, 不正アクセス禁止法.
5. Calculation: availability, transmission time, base conversion, break-even, ROI.
