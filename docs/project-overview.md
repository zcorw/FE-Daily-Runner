# Project Overview

## Purpose

FE Daily Runner is a Python service for generating daily study pages for the
Fundamental Information Technology Engineer Examination.

The runner combines four inputs:

- a date-based study plan
- personal weak-point, mistake, and progress notes
- read-only questions from FE Question Bank Service Runtime
- structured learning content generated by the OpenAI API

The output is a static daily page under `site/`, plus optional progress, state,
run-log, and Telegram notification output.

## Product Boundary

This repository is the consumer application. It is responsible for:

- selecting the daily study plan row
- translating the plan's practice focus into question-bank search requests
- calling the Runtime read APIs
- rendering browser-facing static pages
- writing daily run state and operational logs
- sending Telegram messages only after a successful write

It is not responsible for:

- scraping FE questions
- maintaining the question SQLite database
- reading local question-bank files directly
- using Admin API credentials for normal question reads
- publishing pages through Git commits or pushes

## High-Level Workflow

1. Load configuration from `.env`, process environment, or defaults.
2. Resolve the target date from `--date` or `--today`.
3. Check FE Question Bank Runtime health.
4. Read the study plan, weak points, mistake log, and progress context.
5. Parse the daily `practice_focus` into topic/count targets.
6. Search Runtime candidates for each topic target.
7. Select exactly 10 Subject-A questions where possible.
8. Fetch question details through Runtime `POST /questions/details/batch`.
9. Send only non-question learning context to OpenAI.
10. Inject Runtime question text, choices, answers, and explanations into the
    generated page model.
11. Validate schema, content quality, rendered HTML, image paths, and secret
    leakage.
12. Write dry-run artifacts or formal page output depending on the run mode.
13. Send Telegram only in `--notify` mode and only after the write succeeds.

## Output Policy

Default generated output paths:

```text
site/tmp/dry-run/
site/daily/
site/index.html
personal/progress.md
state/daily_state.json
logs/daily_publish/
logs/openai_token_usage.jsonl
```

Runtime output, logs, and local secrets should stay out of source control.

## Language Policy

The rendered daily page is Japanese-first:

- page chrome and template labels are Japanese
- OpenAI-generated study content is Japanese
- question explanations come from Runtime Japanese explanation fields
- OpenAI must not generate question text, choices, answers, or explanations
