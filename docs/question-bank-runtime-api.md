# Question Bank Runtime API Integration

## Runtime Role

FE Daily Runner depends on FE Question Bank Service Runtime as a read-only
question provider. The runner must not read the question SQLite database or
image cache directly.

Inside Docker Compose, the Runtime must be reachable by service name:

```env
QUESTION_BANK_SERVICE_URL=http://question-bank-runtime:8000
```

Do not use `localhost` or `127.0.0.1` from inside the runner container to reach
the Runtime service.

## Authentication Boundary

Normal runner operation does not use Admin API credentials. Runtime requests are
read-only and must not send an admin token.

## Endpoints Used By The Runner

### `GET /health`

Used before normal workflow execution and by `--health-check`.

Expected response shape:

```json
{
  "ok": true
}
```

Additional Runtime-specific status fields are allowed.

### `GET /keywords`

Optional discovery endpoint for available Runtime search vocabulary.

Expected response shape:

```json
{
  "keywords": ["SQL", "security"]
}
```

The runner can operate without this endpoint in the default workflow, but it is
useful for improving topic matching and smoke tests.

### `POST /questions/candidates/search`

Primary candidate search endpoint.

Request shape:

```json
{
  "keywords": ["security"],
  "topicTags": ["security", "waf", "ids", "dmz"],
  "examPart": "科目A",
  "limit": 3
}
```

The runner builds one request per parsed `practice_focus` bucket. The endpoint
should apply `keywords`, `topicTags`, and `examPart` filtering. It should not
silently return unrelated default questions when the topic has no matches.

Preferred response shape:

```json
{
  "questions": [
    {
      "url": "https://www.fe-siken.com/kakomon/07_haru/a9.html",
      "questionUrl": "https://www.fe-siken.com/kakomon/07_haru/a9.html",
      "examPart": "科目A",
      "matchedKeywords": ["security"],
      "topicTags": ["security", "cryptography"],
      "syllabusArea": "Security",
      "score": 0.94
    }
  ],
  "totalMatched": 1,
  "shortage": {
    "requested": 3,
    "returned": 1,
    "reason": "not_enough_topic_matches"
  }
}
```

The runner normalizes `questionUrl` to `url` when needed.

### `POST /questions/details/batch`

Required detail endpoint for the selected questions.

Request shape:

```json
{
  "urls": [
    "https://www.fe-siken.com/kakomon/07_haru/a9.html"
  ],
  "includeAnswer": true,
  "includeExplanation": true
}
```

Current supported response shape:

```json
{
  "items": [
    {
      "questionId": 1,
      "questionUrl": "https://www.fe-siken.com/kakomon/07_haru/a9.html",
      "sourceUrl": "https://www.fe-siken.com/kakomon/07_haru/a9.html",
      "questionText": "string",
      "choices": [
        {"label": "ア", "text": "string"}
      ],
      "answer": "ア",
      "hasImages": false,
      "images": [],
      "learningExplanation": {
        "explanationJa": "string",
        "distractorExplanationsJa": {
          "イ": "string",
          "ウ": "string",
          "エ": "string"
        },
        "knowledgePointJa": "string",
        "examPointJa": "string",
        "commonTrapJa": "string",
        "sourceExamPart": "科目A",
        "sourceQuestionTextHash": "string"
      },
      "explanationJa": "string",
      "distractorExplanationsJa": {
        "イ": "string",
        "ウ": "string",
        "エ": "string"
      },
      "knowledgePointJa": "string",
      "examPointJa": "string",
      "commonTrapJa": "string",
      "primaryTag": "string",
      "topicTags": ["string"],
      "knowledgePoints": ["string"],
      "syllabusArea": "string"
    }
  ]
}
```

The runner also accepts legacy `questions` top-level arrays and normalizes
choice lists into label-to-text mappings.

Required fields after normalization:

- `url` or `questionUrl`
- `questionText`
- non-empty `choices`
- `answer`
- `explanation` or `explanationJa`
- non-empty `distractor_explanations` or `distractorExplanationsJa`

Question explanations are injected from Runtime. They are not generated by
OpenAI during page creation.

### Optional Lookup Endpoints

The client still supports these read endpoints for tests, smoke checks, and
manual diagnostics:

```http
GET /questions/candidates
GET /questions/by-url?url=<source-url>
GET /questions/{question_id}
```

## Asset URL Boundary

Runtime may return images with `publicPath`, for example:

```json
{"publicPath": "/assets/fe-siken/07_haru/a9_1.png"}
```

Rendered browser pages must use browser-facing `/assets/fe-siken/...` paths.
They must not expose Docker-internal URLs such as
`http://question-bank-runtime:8000/...`.

The web server or reverse proxy that serves the static pages should proxy:

```text
/assets/fe-siken/<path>
```

to:

```text
$QUESTION_BANK_SERVICE_URL/assets/fe-siken/<path>
```
